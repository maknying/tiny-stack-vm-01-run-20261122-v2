A tiny stack virtual machine for make.fun's tiny stack ISA (v1): 32-bit
wrapping integers, a 256-value stack, branches, calls, 256 words of
memory, input/output, and all ten traps with their own exit codes.
Node 22 TypeScript, stdlib only, deterministic. Practice: 40/40, score
1,000,000. Run: `MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out
node main.ts`.
